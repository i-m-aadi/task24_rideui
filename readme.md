# 🚗 Ride Booking UI

A responsive and interactive ride-booking web application built using **HTML5, CSS3, and JavaScript** with **Leaflet.js** for map integration.

The application allows users to select pickup and drop-off locations, calculate an estimated fare based on distance, select a ride type, and simulate the complete ride-booking process with driver assignment and ETA updates.

---

## 📌 Project Overview

The **Ride Booking UI** is a front-end project designed to simulate the basic functionality of applications such as Uber and Ola.

Users can:

- Select a pickup location on an interactive map.
- Select a drop-off location.
- Use their current location as the pickup point.
- Calculate the approximate distance between locations.
- Get an estimated ride fare.
- Select between Bike, Auto, and Car.
- Simulate driver assignment.
- View estimated driver arrival time.
- Track simulated ride-status changes.

This project focuses on practicing **map integration, geolocation, JavaScript DOM manipulation, calculations, and simulated real-time state transitions**.

---

## 🎯 Objective

The main objectives of this project are:

1. Practice integrating an interactive map into a web application.
2. Learn how to capture geographic coordinates.
3. Implement browser-based geolocation.
4. Calculate approximate distance between two locations.
5. Generate a distance-based fare estimate.
6. Simulate a real-world ride-booking workflow.
7. Implement timed state transitions using JavaScript.
8. Create a responsive and user-friendly interface.
